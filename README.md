# EAN-Progamm
A Programm for checking 8 and 13 digit eans.

# Project
A Programm with Menue for checking valid, invalid or placeholder EANs.
8 and 13 digit EANs are allowed.

# Functions
- Menue for every function
- EAN live checker
- Tests for each function
  
# Setup
### 1. Open Directory in CMD where the Project should be saved.

### 2. Clone Repository:
```bash
git clone https://github.com/AlbelNox/EAN-Progamm.git
```

### 3. Open repository in your IDE

### 4. Compile Programm in your IDE

### 5. Use complied Exe to run the program

### 6. Your done, now you can check your EANs!
